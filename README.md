# wilson-game

사과게임(Fruit Box) 기반 웹 퍼즐 게임. 특정 디스코드 서버(루미아 캠퍼스) 멤버 중 학적 인증을 마친 사용자만 플레이하며, 점수는 디스코드 계정에 연동돼 랭킹으로 집계된다.

## 게임 규칙

17×10 격자에 1~9 사과가 무작위로 배치된다. 드래그(터치)로 사각형 영역을 골라 합이 정확히 10이면 제거하고 개수만큼 점수를 얻는다. 제한 시간 120초.

## 주요 기능

- 디스코드 OAuth 로그인 + 서버 멤버십·학적 역할 이중 검증
- 디스코드 계정 기준 최고점 기록(닉네임 바꿔도 중복 없음), 조회 시 닉네임·아바타 최신화
- 상위 10명 랭킹(동점 시 먼저 달성 우선)
- 관리자: 랭킹 새로고침·기록 수정
- 라이트/다크 테마, BGM 제어

## 동작 방식

게임은 HTML5 Canvas 2D + requestAnimationFrame 루프로 렌더한다. 로그인·역할 검증은 봇 토큰으로 서버 측에서 처리하고, 기록은 Vercel Blob에 저장(KST)한다.

## 기술 스택

Next.js 16, React 19, TypeScript, NextAuth v5(Discord OAuth), Vercel Blob, Tailwind + Radix UI. Vercel 배포.
